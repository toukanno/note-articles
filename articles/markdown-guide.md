# Markdownの書き方ガイド

Markdownの基本的な記法をまとめました。

## 見出し

`#` の数で見出しレベルを指定します。

```
# 見出し1
## 見出し2
### 見出し3
```

## テキスト装飾

| 記法 | 表示 |
|------|------|
| `**太字**` | **太字** |
| `*斜体*` | *斜体* |
| `~~取り消し線~~` | ~~取り消し線~~ |
| `` `コード` `` | `コード` |

## リスト

### 順序なしリスト

- 項目1
- 項目2
  - ネストした項目
  - もう一つ

### 順序付きリスト

1. 最初のステップ
2. 次のステップ
3. 最後のステップ

## コードブロック

```python
def greet(name):
    return f"こんにちは、{name}さん！"

print(greet("世界"))
```

## 引用

> Markdownはシンプルで読みやすい記法です。
> 誰でも簡単に使えます。
