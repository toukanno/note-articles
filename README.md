# note-articles

noteアフィリエイト記事を**短期間で量産・運用**するための設計リポジトリです。  
本リポジトリには、以下の3点を収録しています。

1. 500記事の構成（カテゴリ戦略）
2. note向けデザインテンプレート
3. 記事生成プロンプト（量産用）

---

## 1) 500記事の構成（カテゴリ戦略）

500記事は、以下の配分で構築します。

| カテゴリ | 記事数 |
|---|---:|
| AI副業 | 100 |
| アフィリエイト | 100 |
| 投資 | 50 |
| 転職 | 50 |
| ITスキル | 50 |
| SNS運用 | 50 |
| 自動化 | 50 |
| 副業ツール | 50 |
| **合計** | **500** |

### 運用イメージ
- 1日50記事の生成・下書き
- 10日で500記事のベースを構築
- カテゴリごとに内部リンクを設計し、回遊を最大化

---

## 2) note記事テンプレート（デザイン）

以下テンプレートを基準に、各テーマへ展開します。

```md

---

・初期費用ほぼ0  
・AIで自動化できる  
・市場が伸びている

---

## なぜ今○○が熱いのか

市場は今○倍成長しています。

実際に稼いでいる人は
副業だけで月100万以上です。

---

## 稼ぐまでの流れ

STEP1

STEP2  
AIで記事作成

STEP3
```
